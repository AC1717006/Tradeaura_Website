## GitHub Actions Workflows

### `deploy.yml`
- **Trigger:** push to `main`
- **Action:** `aws s3 sync ./ s3://auraautomation.site --delete`
- **Secrets:** `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`

### `news-refresh.yml`
- **Trigger:** cron `0 0,6,12,18 * * *` (every 6h) + `workflow_dispatch`
- **Steps:** `npm ci` → `node scripts/fetch-news.js` → git commit → push
- **Secrets:** `GROQ_API_KEY`, `CURRENTS_API_KEY`, `NEWSDATA_API_KEY`
- **Permissions:** `contents: write`

### `news-admin.yml`
- **Trigger:** `workflow_dispatch` with inputs (`action`, `article_id`)
- **Steps:** `npm ci` → `node scripts/admin-actions.js` → git commit → push
- **Secrets:** `GROQ_API_KEY`

### `instagram-feed.yml`
- **Trigger:** cron `0 * * * *` (every hour) + `workflow_dispatch`
- **Steps:**
  1. Validate secrets exist (shell-level check before Node runs)
  2. `npm ci --omit=dev`
  3. `node scripts/fetch-instagram.js` — fetches API, writes JSON, exits 1 on error
  4. Verify `media.length > 0` in written JSON — refuses to commit empty feed
  5. git commit + push (triggers deploy.yml → S3 sync)
- **Secrets:** `INSTAGRAM_ACCESS_TOKEN`, `INSTAGRAM_USER_ID`
- **Permissions:** `contents: write`

### 1. Stock Ticker — API URL Resolution (`js/stockTicker.js`)

```js
function resolveApiBase() {
  const hostname = window.location.hostname;
  const isLocal  = hostname === 'localhost' || hostname === '127.0.0.1';
  if (isLocal) return 'http://localhost:3001';      // local Express server
  const ticker = document.getElementById('stockTicker');
  if (ticker && ticker.dataset.api) return ticker.dataset.api; // prod Vercel URL
  return 'https://tradeaura.vercel.app';             // hard fallback
}
```

**Why this matters:** The same JS file works on localhost (Live Server port 5500 OR npm start port 3001) AND on S3 production — no manual URL changes needed when deploying.

### 2. Market Ticker — In-Memory Cache (`server.js` / `api/market.js`)

```js
let cache = { data: null, updatedAt: null, fetchedAt: 0 };
const CACHE_TTL_MS = 60 * 1000;   // 60 seconds

app.get('/api/market', async (req, res) => {
  if (cache.data && (Date.now() - cache.fetchedAt) < CACHE_TTL_MS) {
    return res.json({ updatedAt: cache.updatedAt, data: cache.data }); // serve cached
  }
  await refreshCache();            // only hits Yahoo Finance when cache is stale
  return res.json({ updatedAt: cache.updatedAt, data: cache.data });
});
```

**Why this matters:** Yahoo Finance is called at most once per minute regardless of how many users are on the site simultaneously.

### 4. Market Ticker — Price Format with Indian Locale (`js/stockTicker.js`)

```js
function fmtPrice(price, type) {
  const str = parseFloat(price).toLocaleString('en-IN', {
    minimumFractionDigits: 2, maximumFractionDigits: 2,
  });
  return type === 'equity' ? `₹${str}` : str;  // ₹ only for stocks, not indices

```

**Why this matters:** Converts `23547.75` → `23,547.75` using Indian comma placement (lakhs/crores format). Indices (NIFTY, BANK NIFTY) show no ₹ prefix; stocks do.

### 8. Instagram Feed — Defensive Response Extraction (`scripts/fetch-instagram.js`)

```js
function extractItems(apiResponse) {
  if (Array.isArray(apiResponse?.data)) return apiResponse.data;  // { data: [...] }
  if (Array.isArray(apiResponse))       return apiResponse;        // bare array
  return [];                                                        // unexpected shape
}
```

**Why this matters:** The Instagram Graph API always returns `{ "data": [...] }`, but this guard prevents a silent `[]` if the response structure ever changes or a proxy layer unwraps it.

### 9. Instagram Feed — Hard Fail on Empty Media (`scripts/fetch-instagram.js`)

```js
if (rawItems.length > 0 && media.length === 0) {
  throw new Error(
    `normaliseMedia() returned 0 items from ${rawItems.length} API results.`
  );
}
```

**Why this matters:** If the API returns posts but the filter drops them all (regression), the script throws instead of silently writing `media: []` to the JSON. GitHub Actions marks the run as failed and the bad JSON is never committed.

### 10. Instagram Feed — Workflow Guard: Refuse Empty Commit (`.github/workflows/instagram-feed.yml`)

```yaml
- name: Verify instagram-feed.json
  run: |
    MEDIA_COUNT=$(node -e "
      const f = require('./instagram-feed.json');
      process.stdout.write(String(f.media ? f.media.length : 0));
```

**Why this matters:** Double guard — even if the Node script somehow exits 0 with empty media, the workflow verifies the JSON before committing. Empty feeds are never pushed to S3.

### 12. News Pipeline — Deduplication Logic (`scripts/fetch-news.js`)

```js
import 'dotenv/config';
// Article ID = first 12 chars of MD5 hash of originalUrl
const id = crypto.createHash('md5').update(originalUrl).digest('hex').substring(0, 12);
// Skip if already in DB
if (existingIds.has(id)) continue;
```

**Why this matters:** RSS feeds often republish old articles. This hash-based deduplication ensures the same article is never rewritten by GROQ twice, saving API credits and preventing duplicate pages.

### 14. AOS (Animate On Scroll) Init (`js/script.js`)

**Why this matters:** `once: true` is critical — without it, sections re-animate every time you scroll past them, which looks unprofessional. `offset: 60` gives a small "peek" before animation starts.

### 15. Counter Animation (`js/script.js`)

```js
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (!entry.isIntersecting) return;
    const target = parseInt(entry.target.dataset.target);
    const duration = 2000;
    const start = performance.now();
    const tick = (now) => {
      const t = Math.min((now - start) / duration, 1);
      const ease = 1 - Math.pow(1 - t, 3); // cubic ease-out
      entry.target.textContent = Math.round(ease * target);
      if (t < 1) requestAnimationFrame(tick);
    };
    requestAnimationFrame(tick);
    observer.unobserve(entry.target); // only run once
  });
});
```

**Why this matters:** Uses `IntersectionObserver` (not scroll events) for performance. The cubic ease-out formula `1 - (1-t)³` makes numbers accelerate then slow down naturally. `requestAnimationFrame` keeps it smooth at 60fps.
